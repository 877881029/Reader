# Reader 功能全解

版本 **0.1.0**（仍在迭代，不是 1.0）  
整理日期：2026-09-21  
仓库路径：`docs/Reader功能全解.md`  
对应本机入口：桌面 `Reader.lnk` → `dist\Reader\Reader.exe`

Reader 是 Windows 上的文档查看器：双击文件就能读，纸色界面，记事本式标签。没有 Microsoft Office 也能用。当前只做 Windows。

---

## 1. 一句话能做什么

打开并阅读：Word、PPT、Excel、Markdown、纯文本、PDF、JSON / YAML / XML、C / C++ 源码和头文件、SVG、常见图片。
多文件用标签页；每次双击文件开一个新窗口（像记事本），所有窗口共用一个后台进程，第二次起几乎即时打开；标签可以拖出成新窗口或拖进别的窗口。  
本机已把这些后缀的**当前用户默认程序**设成 Reader（含 `.pdf`、`.txt`、`.svg`、图片和完整 C / C++ 后缀族）。

---

## 2. 怎么打开文件

| 方式 | 行为 |
|---|---|
| 资源管理器双击 | 用 Reader 打开该文件（默认程序），**每次一个新窗口**；**不会先闪欢迎页再关掉**。视觉页要等画完才从纸色加载切到内容。Reader 已在运行时，启动器不加载界面库，直接把文件交给已运行的进程，新窗口几乎即时出现 |
| 桌面图标 / 空启动 | 先出窗口和欢迎页（Reader 已在运行时再开一个新的欢迎窗口）；Chromium 预热往后稍稍，避免开机后第一次卡住。只打开文本/代码、图片、SVG、`.bin` 时 Chromium 预热推迟约 2 秒，让文件先显示 |
| 拖到窗口里 | 支持的文件追加为新标签 |
| `Ctrl+O` | 多选打开对话框 |
| 欢迎页「打开文件」 | 同上 |
| 欢迎页「最近打开」 | 点卡片再开 |
| 已经打开过的同一路径 | 切到已有标签（在哪个窗口就切到哪个窗口），不重复开 |

打开对话框筛选：`.docx` `.pptx` `.xlsx` `.md` `.pdf` `.json` `.yaml` `.yml` `.xml` `.c` `.h` `.cpp` `.hpp` `.cc` `.cxx` `.hh` `.hxx` `.inl` `.ipp` `.txt` `.svg` `.png` `.jpg` `.jpeg` `.gif` `.webp` `.bmp`。

不支持的文件会拒绝（例如旧版 `.doc` / `.ppt` / `.xls`、HTML、文件夹、RAW / HEIC）。

## 3. 窗口长什么样

记事本式**一行标题栏**，没有「文件 / 编辑 / 查看」菜单。

从左到右：

1. 蓝色 **R** 图标  
2. 打开的标签  
3. **`+`**：弹出带图标的新建菜单——**新建文件**（可编辑 Markdown 草稿 `未命名-….md`）、**打开文件**（只列 Reader 支持的格式）、**Browser**（标签内网页浏览，见 5.8）、**Terminal**（子菜单 PowerShell / Command Prompt 真终端，见 5.9）  
4. 空白处：拖动窗口；双击最大化 / 还原  
5. **编辑 | 预览** 切换：仅当前是 Markdown 标签时出现在窗口按钮左侧，作用与 `Ctrl+I` / `Ctrl+T` 相同  
6. 最小化 / 最大化 / 关闭

默认大小 1200×640，最小约 800×400。四边可以拉伸。最大化按钮支持 Windows 11 贴靠布局。

关掉最后一个标签后回到欢迎页，不会留一个空标签。状态栏隐藏，预览状态不占底边。

任务栏按钮用蓝色 R，不是窗口缩略图。

界面文字用 Microsoft YaHei UI（中英文都在同一个字体里，英文字形同 Segoe UI），标题栏和浏览器工具栏的符号按钮用 Segoe UI Symbol。这样启动时 Qt 不用为缺字去翻遍系统字体，首屏更快。

### 多窗口与移动标签

- 每次从资源管理器打开都是新窗口，所有窗口在同一个后台进程里
- **拖出标签**：按住标签往下（或往上）拖出标签条，松开：
  - 落在另一个 Reader 窗口上 → 标签移进那个窗口（落在它的某个标签上就插在那个位置）
  - 落在空白处 → 成为一个新窗口，出现在鼠标位置
  - 窗口只有这一个标签时：落在空白处就是移动整个窗口，落在别的 Reader 窗口上就合并过去并关掉原窗口
- **右键标签**：「移到新窗口」（只剩一个标签时不可用）、「关闭标签」
- 移动不会重新加载：未保存的编辑（标签 `*`）、撤销记录、Markdown 编辑/预览、终端会话、正在加载的预览都原样带过去；原窗口被移空时直接关闭，不会询问保存

## 4. 欢迎页

空启动（或关光所有标签）显示欢迎页，左右分栏，配色为 Copilot 式简约中性色（纸色底、墨色主按钮、细线卡片、灰色类型徽章，无大面积蓝色和背景水印）：

- 左：Reader、`VERSION 0.1.0`、「打开文件」、「新建 Markdown」，提示「拖入文件，或按 Ctrl+O 打开」
- 右：「最近打开」卡片（类型徽章 + 文件名 + 路径）。**Ctrl+F** 在「最近打开」同一行弹出隐藏路径框（窗口查找条仍不出现）。输入目录后回车，下列出该层子目录（徽章 `DIR`）和 Reader 能打开的文件（卡片样式与最近打开相同）；点目录会把路径框改成该目录并继续列出下一层。输入文件路径后回车即打开。Esc 关掉路径框并回到最近打开。左侧不变。

最近文件记在 `%LOCALAPPDATA%\Reader\recent.json`，最多 12 条；成功打开才写入；文件已经不在磁盘上会清掉。草稿 `未命名-*.md` 不进最近列表。

## 5. 各格式怎么读

### 5.1 PowerPoint（`.pptx`）— 默认视觉预览

像幻灯片阅读器，不经过 PowerPoint：

- 左侧缩略图，点一下跳页  
- 右侧一张幻灯片（按原稿比例，周围留边）  
- 上一张 / 下一张、页码、缩放、**适合窗口**  
- 打开即按窗口大小**居中适配**，四周留边，画布没有滚动条  
- 缩放：工具栏 `-` / `+`，或 `Ctrl+=` 放大、`Ctrl+-` 缩小、`Ctrl+0` 适合窗口、`Ctrl+滚轮`；放大到超出窗口后可按住左键拖动或用滚轮（Shift+滚轮横向）平移  
- 键盘：← →、PageUp / PageDown、Home / End  

能画背景、图、文字样式、常见形状、表格、基础图表。动画、视频、宏不播放。缺字体就替换，单页解析失败只影响那一页。表格表头若是深色底浅色字，会按原稿颜色显示，不会被吃掉。

加密或损坏会报错。视觉渲染失败时会退回「文本模式」（大纲式 HTML）。

### 5.2 Markdown（`.md`）

**已有文件**：默认只读渲染（不是源码编辑器）。

渲染内容：

- 标题层级、表格、代码块、引用、链接  
- 围栏 `mermaid` 离线画成图（流程图、时序、类图等，以内置 Mermaid 版本为准）  
- Obsidian 风格 `[[笔记名]]` / `[[笔记名\|显示名]]`：点了会打开**同一目录下**的 `.md`；找不到只提示，不会全盘搜索  
- 文档里的相对图片可以显示  
- 页面**不能**访问外网；文档里的原始 HTML/JS 不会执行  

**编辑：**

| 操作 | 结果 |
|---|---|
| `+` →「新建文件」或欢迎页「新建 Markdown」 | 空白草稿，直接可打字 |
| `Ctrl+I` 或标题栏「编辑」 | 当前 `.md` 切到源码编辑 |
| `Ctrl+S` | 保存（无路径会另存） |
| `Ctrl+T` 或标题栏「预览」 | 回到渲染，**直接显示编辑器里的当前内容，不需要先保存**；新建稿也不弹另存为（未保存时标签仍显示 `*`，关闭时照常询问） |

编辑与预览像 VS Code / Typora 一样无缝切换：每个 Markdown 标签同时保留编辑器和预览，切换只是换显示（实测约 5–15ms），光标、撤销记录和滚动位置都保留；编辑时内容会在后台实时同步到预览，新建或进入编辑后预览会在后台提前准备好。保存只在你按 `Ctrl+S` 时发生（预览模式下也可以保存）。关掉标签再打开文件，又是渲染。

`Ctrl+I` / `Ctrl+T` 只对 Markdown 标签有效，PPTX 上按了没反应。

### 5.3 PDF（`.pdf`）

Chromium 内置阅读器，只读。直接读你的原文件，不另拷一份。翻页、缩放走 PDF 查看器自己的控件。`Ctrl+F` 可以搜正文。

### 5.4 Word / Excel（`.docx` / `.xlsx`）

默认内置 HTML 预览（快，不调 Office）。版式不是 Word/Excel 像素级还原。可选「Office 高保真」（用本机 Word/Excel 导出）目前**没有标题栏按钮**，动作留在程序里，日常先看内置预览即可。

没有安装 Office 完全能打开这两类文件。

### 5.5 代码（JSON / YAML / XML / C / C++）

记事本式可编辑代码页，不是 IDE：

- 左侧 VS Code 式行号  
- 底部记事本式状态栏，只显示、不可点击：`Ln 87, Col 19 | Size 12 pt | Type JSON`（类型：JSON、YAML、XML、C、C++、C/C++ Header、C++ Header、Plain text）
- `Ctrl+J` 转到行（与 `Ctrl+F` 同样在标题栏下方出现输入条）；超过范围时自动限制到首尾行
- `Alt+Z` 在横向滚动和按窗口宽度折行之间切换
- 文本里的 `http://` / `https://` 网址：按住 Ctrl 悬停会显示下划线和手形，`Ctrl+单击` 用默认浏览器打开（Markdown 编辑视图同样适用；不打开其他协议）
- `Ctrl+=` / `Ctrl+-` / `Ctrl+0`（恢复 12pt）或 `Ctrl+滚轮` 在 8–24pt 内调整等宽字体，状态栏同步显示
- 语法高亮（轻量着色，不是校验器；坏掉的 JSON/XML 仍当文本显示；C 不是编译器）  
- 可选中、可复制  
- 默认不自动折行，过长向右滚
- 可直接输入、撤销/重做；Ctrl+S 原地保存，Ctrl+Shift+S 另存为，标签名前 * 表示未保存  
- 编码与换行原样保留（UTF-8 / UTF-8 BOM / UTF-16 BOM / GB18030，CRLF 或 LF）；写入走同目录临时文件 + 原子替换  
- 无法无损识别编码时显示「只读：无法无损识别编码」，可看不可存，原文件字节不会被改  

`.yml` 和 `.yaml` 同一套高亮。`.c`、`.h`、`.cpp`、`.hpp`、`.cc`、`.cxx`、`.hh`、`.hxx`、`.inl` 和 `.ipp` 同一套 C-family 高亮（关键字、数字、字符串、注释、预处理指令）。
每个代码标签页各自保存跳转位置、换行和字号。

### 5.5.1 纯文本（`.txt`）

同样走可编辑代码页：行号、撤销/重做、`Ctrl+S` 保存，编码与换行规则同上。**没有**语法高亮，避免把普通笔记当成 JSON 上色。状态为「文本预览」。`Ctrl+N` 新建 `未命名.txt`（UTF-8、CRLF，与记事本一致），首次保存弹出另存为。

### 5.6 SVG（`.svg`）

只读图形预览，不是 XML 源码页：

- 纸色底，图形按比例适窗，周围留边  
- 用 QtSvg 画静态图形；**不执行** SVG 里的脚本，也不播 SMIL 动画  
- 损坏或不是合法 SVG 仍会开标签，中间提示「无法渲染此 SVG」  
- `Ctrl+F` 搜源码文本（无高亮）  
- **缩放没有按钮、滑条或百分比**：`Ctrl+滚轮` 放大/缩小（对准鼠标位置）；放大后可按住左键拖动。普通滚轮不缩放  
- 没有 Office / 视觉 / 文本模式  

### 5.7 图片（`.png` / `.jpg` / `.jpeg` / `.gif` / `.webp` / `.bmp`）

只读图片预览，和 SVG 同一套纸色画布：

- 按比例适窗  
- `Ctrl+滚轮` 缩放，没有明面缩放控件  
- 动画 GIF / 动画 WebP 只显示第一帧  
- 损坏文件仍开标签，中间提示「无法打开此图片」  
- `Ctrl+F` 没有可搜正文  

### 5.8 浏览器（`+` → Browser）

标签内的轻量网页浏览：

- 顶部后退 / 前进 / 刷新和地址栏「输入网址或搜索」
- 输入 `example.com` 自动补 `https://`，`localhost:端口` 补 `http://`；`http/https/file` 网址原样打开；其他文字（包括 `javascript:`、`data:`）一律当搜索词交给 Bing
- 标签名跟随网页标题，初始为「浏览器」
- 使用独立的无痕 profile：不往磁盘写 cookie/缓存，也和 Markdown/PPTX 离线预览互不影响（离线预览仍然禁止联网）
- `Ctrl+F` 可在网页内查找；不进「最近打开」，关闭时不询问保存
- 没有书签、历史面板、下载管理和开发者工具

### 5.9 终端（`+` → Terminal → PowerShell / Command Prompt）

标签内的真终端（Windows 伪控制台 ConPTY + xterm.js），与 Copilot 右侧终端同类：

- 子菜单二选一：**PowerShell**（Windows PowerShell 5.1）或 **Command Prompt**（cmd）；标签名即所选 shell；只以普通权限运行（不提供管理员模式）
- 起始目录：当前标签是真实文件时用它所在文件夹，否则用户主目录
- 完整交互：颜色、`Tab` 补全、方向键历史、PSReadLine 语法着色、全屏程序都可用；随标签大小自动调整行列
- 配色与 Copilot 浅色主题一致：米白底 `#fbf9f5`、深墨字与光标、浅灰选区、GitHub Light 16 色；字体 Cascadia Mono
- 有选中文字时 `Ctrl+C` 复制，否则 `Ctrl+C` 中断当前命令；`Ctrl+V` 粘贴
- 终端标签在前台时，Reader 的 `Ctrl+O/F/H/J/N/S` 等文档快捷键暂时让给 shell，切回文档标签恢复
- shell 退出后显示「[进程已退出，按 Enter 重新启动]」，回车按同一 shell 重启
- 终端页离线：只加载内置终端界面，不联网；输出里的网址不可点击
- 关闭标签或窗口即结束进程，不询问；不进「最近打开」

### 5.10 二进制（`.bin`）

十六进制查看器，只读：

- 每行 16 字节：左侧偏移（8 位十六进制，超过 4 GiB 自动加宽）、中间数据、右侧 ASCII（`0x20`–`0x7E` 原样显示，其余为 `.`）
- 顶部 **Byte / Word / DWord** 切换分组；Word / DWord 按**小端**显示数值（如字节 `00 01 02 03` 显示为 `03020100`），文件末尾不足一组时缺的高位显示 `--`
- 鼠标停在某个十六进制单元或某个 ASCII 字符上，两侧同时高亮同一组；工具栏显示该组的偏移和数值（十六进制 + 十进制）
- 打开不读全文件：用内存映射，只绘制屏幕上的行，GB 级文件也能立即显示并滚到末尾
- 字号随窗口宽度自动调整，让一行铺满窗口（上限后居中），第 7、8 字节之间留出半行间隔；`Ctrl+滚轮` / `Ctrl+=` / `Ctrl+-` 手动缩放，`Ctrl+0` 恢复自动
- 高亮与鼠标所在字节严格对齐；鼠标落在两组之间的空隙时归最近的一组
- 滚轮、PageUp / PageDown、方向键滚动；关闭标签即释放文件，不占用
- 暂不支持编辑、二进制内查找、按偏移跳转和大端显示

## 6. 查找（记事本式）

打开**任意文档标签**后：

| 按键 | 作用 |
|---|---|
| `Ctrl+F` | 标题栏下方出现查找条 |
| `Enter` / `F3` | 下一个 |
| `Shift+Enter` / `Shift+F3` | 上一个 |
| `Esc` 或条上的 × | 关掉；Web 预览里的高亮一并清掉 |

条上有：

- 输入框（占位「查找」）  
- **Aa**：区分大小写（默认关）  
- **上一个 / 下一个**  
- 一个都没有时显示 **未找到**  

搜到尽头会绕回开头。欢迎页上 `Ctrl+F` 打开右侧路径框，不打开窗口查找条。  
**替换（`Ctrl+H`）**：仅在可编辑的文本页（TXT、JSON/YAML/XML/C/C++、Markdown 编辑模式）可用，查找条多出「替换为」框和「替换 / 全部替换」。「替换」只替换当前选中的匹配再跳到下一处；「全部替换」一次完成、可整体撤销，条上显示「已替换 N 处」。遵循 **Aa** 大小写开关，不支持正则。只读文件按了没反应。

**转到行（`Ctrl+J`，`Ctrl+G` 同效）**：任意纯文本页（含只读代码/TXT 和 Markdown 编辑）在查找条位置出现「转到行（1–N）」输入条，回车后光标跳到行首并居中、输入条关闭；不是数字时提示「无效行号」；`Esc` 或 × 关闭。与查找条互斥。

纯文本（Markdown 源码、JSON 等）走文本查找；Markdown 渲染、PPTX 视觉、PDF、HTML 预览走页面内查找；SVG 搜源码字符串；图片没有正文。

## 7. 快捷键一览

| 快捷键 | 作用 |
|---|---|
| `Ctrl+O` | 打开文件 |
| `Ctrl+F` | 文档内查找；欢迎页则打开右侧路径框（可点进子目录） |
| `F3` | 查找下一个 |
| `Shift+F3` | 查找上一个 |
| `Ctrl+H` | 替换（可编辑文本页） |
| `Ctrl+J` | 转到行（纯文本页；`Ctrl+G` 同效） |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 代码/TXT/BIN：字号放大 / 缩小 / 恢复（BIN 恢复为自动适配）；PPTX：放大 / 缩小 / 适合窗口 |
| `Alt+Z` | 代码/TXT：自动换行开关 |
| `Ctrl+单击` 网址 | 代码/TXT/Markdown 编辑：用默认浏览器打开 http(s) 链接 |
| `Esc` | 关闭查找条 |
| `Ctrl+S` | 保存当前编辑页（Markdown 编辑、TXT、JSON/YAML/XML/C/C++） |
| `Ctrl+Shift+S` | 另存为 |
| `Ctrl+N` | 新建纯文本 `未命名.txt` |
| `Ctrl+I` | Markdown：渲染 → 编辑 |
| `Ctrl+T` | Markdown：编辑 → 渲染 |
| `Ctrl+滚轮` | SVG / 图片 / PPTX：放大或缩小；代码/TXT/BIN：调字号 |
| PPTX 内 ← → / PageUp / PageDown / Home / End | 翻幻灯片 |

标题栏 **`+`** 弹出新建菜单（新建文件 / 打开文件 / Browser / Terminal）；Markdown 标签有「编辑 | 预览」切换按钮。关闭有未保存修改的标签或窗口时会询问「保存 / 不保存 / 取消」；打开文件不会覆盖已编辑的未命名草稿。没有可见的「新建窗口」按钮；从资源管理器每次打开都是新窗口，标签可拖出成新窗口或拖进别的窗口（见第 3 节）。

## 8. 默认打开方式

启动 Reader 时，会把当前用户下这些后缀指到 Reader：

`.docx` `.pptx` `.xlsx` `.md` `.pdf` `.json` `.yaml` `.yml` `.xml` `.c` `.h` `.cpp` `.hpp` `.cc` `.cxx` `.hh` `.hxx` `.inl` `.ipp` `.txt` `.svg` `.png` `.jpg` `.jpeg` `.gif` `.webp` `.bmp`

- 不需要管理员。  
- 不伪造 Windows 的 UserChoice 校验。  
- `.pdf` / `.txt` 被系统锁死后，若还不是 Reader，会短暂打开一次「设置 → Reader 的默认应用」页，由系统自己改；已经是 Reader 则不再弹。  
- 也会刷新桌面快捷方式（已有快捷方式默认不覆盖；本机日常用的 `Reader.lnk` 指向冻结后的 exe）。

在「设置 → 应用 → 默认应用」里可以看到 Reader，按文件类型也能再改回去。

## 10. 单实例与多文件

同一时间一个 Reader 进程。再启动一次、或从资源管理器「打开方式」再送文件，会转到已有窗口并加标签。一次选多个文件 = 多个标签。

图标是透明底的蓝色 R（exe、窗口、任务栏、快捷方式、文件关联同一套）。

## 11. 明确不做（0.1.0）

- 翻译、左右对照  
- 格式互转（docx↔pdf 等）  
- 替换（Ctrl+H）、Markdown 以外的编辑  
- PPT 动画 / 视频 / 宏  
- Obsidian 仓库、标签、`![[嵌入]]`、Dataview  
- RAW / TIFF / ICO / HEIC  
- 图形页上的缩放按钮或百分比  
- macOS / Linux  
- 记住上次窗口大小  

「Office 高保真 / PPT 文本模式」在代码里还在，标题栏目前没有入口；默认已经是内置 HTML（Word/Excel）和视觉幻灯片（PPT）。

## 12. 同事怎么跑源码

需要 Windows 10/11、Python 3.12+、打 exe 时还要 Node 18+。仓库根目录：

```text
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\setup.ps1
```

会建 `.venv`、装依赖、调用 `scripts\build_windows.ps1` 打出 `dist\Reader\Reader.exe`，然后启动这份 exe。`dist/` 不进 git。

只装并构建、不启动：`scripts\setup.ps1 -SkipLaunch`。  
只要源码运行、不打 exe：`scripts\setup.ps1 -SkipBuild`。  
也可以单独再跑 `scripts\build_windows.ps1`。

日常用法：桌面图标打开 Reader，或直接双击文档。Markdown 用 `Ctrl+I` / `Ctrl+T` 在源码和渲染之间切；任何文档用 `Ctrl+F` 查找。
