# Reader 功能全解

版本 **0.1.0**（仍在迭代，不是 1.0）  
整理日期：2026-09-11  
仓库路径：`docs/Reader功能全解.md`  
对应本机入口：桌面 `Reader.lnk` → `dist\Reader\Reader.exe`

Reader 是 Windows 上的文档查看器：双击文件就能读，纸色界面，记事本式标签。没有 Microsoft Office 也能用。当前只做 Windows。

---

## 1. 一句话能做什么

打开并阅读：Word、PPT、Excel、Markdown、PDF、JSON / YAML / XML、SVG、常见图片。  
多文件用标签页；第二次再开 Reader 会把文件送到已经开着的窗口。  
本机已把这些后缀的**当前用户默认程序**设成 Reader（含 `.pdf`、`.svg`、图片）。

---

## 2. 怎么打开文件

| 方式 | 行为 |
|---|---|
| 桌面图标 | 空启动，先出欢迎页 |
| 资源管理器双击 | 用 Reader 打开该文件（默认程序）；**不会先闪欢迎页再关掉** |
| 拖到窗口里 | 支持的文件追加为新标签 |
| `Ctrl+O` | 多选打开对话框 |
| 欢迎页「打开文件」 | 同上 |
| 欢迎页「最近打开」 | 点卡片再开 |
| 已经打开过的同一路径 | 切到已有标签，不重复开 |

打开对话框筛选：`.docx` `.pptx` `.xlsx` `.md` `.pdf` `.json` `.yaml` `.yml` `.xml` `.svg` `.png` `.jpg` `.jpeg` `.gif` `.webp` `.bmp`。

不支持的文件会拒绝（例如旧版 `.doc` / `.ppt` / `.xls`、HTML、文件夹、RAW / HEIC）。

---

## 3. 窗口长什么样

记事本式**一行标题栏**，没有「文件 / 编辑 / 查看」菜单。

从左到右：

1. 蓝色 **R** 图标  
2. 打开的标签  
3. **`+`**：新建一个可编辑的 Markdown 草稿（`未命名-….md`）  
4. 空白处：拖动窗口；双击最大化 / 还原  
5. 最小化 / 最大化 / 关闭  

默认大小 1200×640，最小约 800×400。四边可以拉伸。最大化按钮支持 Windows 11 贴靠布局。

关掉最后一个标签后回到欢迎页，不会留一个空标签。状态栏隐藏，预览状态不占底边。

任务栏按钮用蓝色 R，不是窗口缩略图。

---

## 4. 欢迎页

空启动（或关光所有标签）显示欢迎页，左右分栏：

- 左：Reader、`VERSION 0.1.0`、「打开文件」、「新建 Markdown」，提示「拖入文件，或按 Ctrl+O 打开」
- 右：「最近打开」卡片（类型徽章 + 文件名 + 路径）

最近文件记在 `%LOCALAPPDATA%\Reader\recent.json`，最多 12 条；成功打开才写入；文件已经不在磁盘上会清掉。草稿 `未命名-*.md` 不进最近列表。

---

## 5. 各格式怎么读

### 5.1 PowerPoint（`.pptx`）— 默认视觉预览

像幻灯片阅读器，不经过 PowerPoint：

- 左侧缩略图，点一下跳页  
- 右侧一张幻灯片（按原稿比例，周围留边）  
- 上一张 / 下一张、页码、缩放、**适合窗口**  
- 键盘：← →、PageUp / PageDown、Home / End  

能画背景、图、文字样式、常见形状、表格、基础图表。动画、视频、宏不播放。缺字体就替换，单页解析失败只影响那一页。

加密或损坏会报错。视觉渲染失败时会退回「文本模式」（大纲式 HTML）。

### 5.2 Markdown（`.md`）

**已有文件**：默认只读渲染（不是源码编辑器）。

渲染内容：

- 标题层级、表格、代码块、引用、链接  
- 围栏 `mermaid` 离线画成图（流程图、时序、类图等，以内置 Mermaid 版本为准）  
- Obsidian 风格 `[[笔记名]]` / `[[笔记名\|显示名]]`：点了会打开**同一目录下**的 `.md`；找不到只提示，不会全盘搜索  
- 文档里的相对图片可以显示  
- 页面**不能**访问外网；文档里的原始 HTML/JS 不会执行  

**编辑：**

| 操作 | 结果 |
|---|---|
| `+` 或欢迎页「新建 Markdown」 | 空白草稿，直接可打字 |
| `Ctrl+I` | 当前 `.md` 切到源码编辑 |
| `Ctrl+S` | 保存（无路径会另存） |
| `Ctrl+T` | 回到渲染；有未保存修改会先强制保存；另存取消则留在编辑器 |

新建稿保存后**不会**自动切回渲染，要 `Ctrl+T`。关掉标签再打开文件，又是渲染。

`Ctrl+I` / `Ctrl+T` 只对 Markdown 标签有效，PPTX 上按了没反应。

### 5.3 PDF（`.pdf`）

Chromium 内置阅读器，只读。直接读你的原文件，不另拷一份。翻页、缩放走 PDF 查看器自己的控件。`Ctrl+F` 可以搜正文。

### 5.4 Word / Excel（`.docx` / `.xlsx`）

默认内置 HTML 预览（快，不调 Office）。版式不是 Word/Excel 像素级还原。可选「Office 高保真」（用本机 Word/Excel 导出）目前**没有标题栏按钮**，动作留在程序里，日常先看内置预览即可。

没有安装 Office 完全能打开这两类文件。

### 5.5 代码（`.json` / `.yaml` / `.yml` / `.xml`）

只读代码页，不是 IDE：

- 左侧 VS Code 式行号  
- 语法高亮（轻量着色，不是校验器；坏掉的 JSON/XML 仍当文本显示）  
- 可选中、可复制  
- 不自动折行，过长向右滚  
- UTF-8 读取，非法字节替换显示  

`.yml` 和 `.yaml` 同一套高亮。

### 5.6 SVG（`.svg`）

只读图形预览，不是 XML 源码页：

- 纸色底，图形按比例适窗，周围留边  
- 用 QtSvg 画静态图形；**不执行** SVG 里的脚本，也不播 SMIL 动画  
- 损坏或不是合法 SVG 仍会开标签，中间提示「无法渲染此 SVG」  
- `Ctrl+F` 搜源码文本（无高亮）  
- **缩放没有按钮、滑条或百分比**：`Ctrl+滚轮` 放大/缩小（对准鼠标位置）；放大后可按住左键拖动。普通滚轮不缩放  
- 没有 Office / 视觉 / 文本模式  

### 5.7 图片（`.png` / `.jpg` / `.jpeg` / `.gif` / `.webp` / `.bmp`）

只读图片预览，和 SVG 同一套纸色画布：

- 按比例适窗  
- `Ctrl+滚轮` 缩放，没有明面缩放控件  
- 动画 GIF / 动画 WebP 只显示第一帧  
- 损坏文件仍开标签，中间提示「无法打开此图片」  
- `Ctrl+F` 没有可搜正文

## 6. 查找（记事本式）

打开**任意文档标签**后：

| 按键 | 作用 |
|---|---|
| `Ctrl+F` | 标题栏下方出现查找条 |
| `Enter` / `F3` | 下一个 |
| `Shift+Enter` / `Shift+F3` | 上一个 |
| `Esc` 或条上的 × | 关掉；Web 预览里的高亮一并清掉 |

条上有：

- 输入框（占位「查找」）  
- **Aa**：区分大小写（默认关）  
- **上一个 / 下一个**  
- 一个都没有时显示 **未找到**  

搜到尽头会绕回开头。欢迎页上 `Ctrl+F` 无效。  
**没有替换（Ctrl+H）。**

纯文本（Markdown 源码、JSON 等）走文本查找；Markdown 渲染、PPTX 视觉、PDF、HTML 预览走页面内查找；SVG 搜源码字符串；图片没有正文。

---

## 7. 快捷键一览

| 快捷键 | 作用 |
|---|---|
| `Ctrl+O` | 打开文件 |
| `Ctrl+F` | 查找 |
| `F3` | 查找下一个 |
| `Shift+F3` | 查找上一个 |
| `Esc` | 关闭查找条 |
| `Ctrl+S` | 保存当前 Markdown 编辑页 |
| `Ctrl+I` | Markdown：渲染 → 编辑 |
| `Ctrl+T` | Markdown：编辑 → 渲染 |
| `Ctrl+滚轮` | SVG / 图片：放大或缩小（无明面控件） |
| PPTX 内 ← → / PageUp / PageDown / Home / End | 翻幻灯片 |

标题栏 **`+`** 新建 Markdown。没有可见的「新建窗口」按钮；日常靠单实例把文件并进当前窗口。

## 8. 默认打开方式

启动 Reader 时，会把当前用户下这些后缀指到 Reader：

`.docx` `.pptx` `.xlsx` `.md` `.pdf` `.json` `.yaml` `.yml` `.xml` `.svg` `.png` `.jpg` `.jpeg` `.gif` `.webp` `.bmp`

- 不需要管理员。  
- 不伪造 Windows 的 UserChoice 校验。  
- `.pdf` 被系统锁死后，若还不是 Reader，会短暂打开一次「设置 → Reader 的默认应用」页，由系统自己改；已经是 Reader 则不再弹。  
- 也会刷新桌面快捷方式（已有快捷方式默认不覆盖；本机日常用的 `Reader.lnk` 指向冻结后的 exe）。

在「设置 → 应用 → 默认应用」里可以看到 Reader，按文件类型也能再改回去。

## 9. 外观

整窗纸色，打开文件后不会突然变成冷白或深色壳。

| 用途 | 颜色 |
|---|---|
| 纸面 / 正文底 | `#f4efe6` |
| 标题栏 | `#ebe4d8` |
| 正文 | `#1c1915` |
| 次要文字 | `#8a8176` |
| 强调 / 链接 / 徽章 | `#2563eb` |

PPT 幻灯片画布和 PDF 页面像素保持原稿（白底幻灯片仍是白的）。关闭按钮悬停仍是系统红。

---

## 10. 单实例与多文件

同一时间一个 Reader 进程。再启动一次、或从资源管理器「打开方式」再送文件，会转到已有窗口并加标签。一次选多个文件 = 多个标签。

图标是透明底的蓝色 R（exe、窗口、任务栏、快捷方式、文件关联同一套）。

---

## 11. 明确不做（0.1.0）

- 翻译、左右对照  
- 格式互转（docx↔pdf 等）  
- 替换（Ctrl+H）、Markdown 以外的编辑  
- PPT 动画 / 视频 / 宏  
- Obsidian 仓库、标签、`![[嵌入]]`、Dataview  
- RAW / TIFF / ICO / HEIC  
- 图形页上的缩放按钮或百分比  
- macOS / Linux  
- 记住上次窗口大小  

「Office 高保真 / PPT 文本模式」在代码里还在，标题栏目前没有入口；默认已经是内置 HTML（Word/Excel）和视觉幻灯片（PPT）。

---

## 12. 同事怎么跑源码

需要 Windows 10/11、Python 3.12+。仓库根目录：

```text
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\setup.ps1
```

会建 `.venv`、装依赖并启动。首次启动会写打开方式和桌面快捷方式。

只装不启动：`scripts\setup.ps1 -SkipLaunch`。  
本地再打一份安装目录：`scripts\build_windows.ps1`（产物 `dist\Reader\Reader.exe`，体积大约六百兆，含 Chromium）。`dist/` 不进 git。

---

日常用法：桌面图标打开 Reader，或直接双击文档。Markdown 用 `Ctrl+I` / `Ctrl+T` 在源码和渲染之间切；任何文档用 `Ctrl+F` 查找。
