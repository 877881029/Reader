# 重新打开刚关闭的标签（B2）

日期：2026-10-16
状态：已批准（开发列表 B2；用户要求本次发布版本号推进到 1.2.17）
进度：`docs/STATUS.md`

## 1. 目标

像浏览器一样，按 `Ctrl+Shift+T` 重新打开刚关闭的标签，误关的文件一键找回。

## 2. 行为

- 可重新打开的是「对应磁盘上真实文件」的标签（各种格式都算）。未命名草稿（关闭时选了不保存）、终端、浏览器标签不记录：它们的内容是用户主动放弃的，或者重开只会得到一个新的空会话。
- 记录：关闭标签（用户确认保存/不保存后）、正常关闭整个窗口时，把这些标签的文件路径记入「最近关闭」列表。列表由所有窗口共享，最多 20 条，同一路径只保留最近一次。
- `Ctrl+Shift+T`：取最近关闭且仍存在的文件，在当前窗口重新打开；如果它已经在某个窗口里打开，就切到那个窗口的那个标签。已不存在的文件跳过。列表为空时状态提示「没有可重新打开的标签」。
- 标签右键菜单增加「重新打开关闭的标签」，与快捷键相同。
- 终端标签在前台时 `Ctrl+Shift+T` 仍归 Reader（与其他文档快捷键不同，shell 不使用这个组合）。

## 3. 测试

- 列表：后进先出、同路径去重置顶、上限 20、跳过已删除文件。
- 窗口：关闭文件标签后按快捷键重新打开；未命名草稿不记录；列表为空时提示；整个窗口关闭后其文件标签可在另一窗口找回；已在别的窗口打开时切过去。
- README 快捷键表包含 `Ctrl+Shift+T`。
